# dotfiles

My Arch Linux configuration files. Terminal-first workflow with neovim, shell customizations, and daily-driver setup.

## What's Inside

- **neovim** — Lua-based configuration with LSP, treesitter, and custom keymaps
- **shell** — bash/zsh configuration, aliases, and prompt
- **terminal** — kitty/alacritty settings
- **system** — Arch packages, services, and automation

## Quick Start

```bash
git clone https://github.com/amirtanazzoh/dotfiles.git ~/dotfiles
cd ~/dotfiles
# Review and symlink what you need
```

> These are personal configs. Review before using — they're built for my workflow.
